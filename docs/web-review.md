## 启动

项目根目录先执行`uv sync --locked`安装锁定依赖，再在PowerShell执行：

```powershell
./scripts/start_web.ps1
```

每次启动或重启后，脚本等待首页就绪，再通过默认浏览器自动打开http://127.0.0.1:4001；指定-Port时使用对应端口。等待上限60秒，服务仍在当前终端前台运行。

本机打开http://127.0.0.1:4001，同局域网打开http://PC的局域网IP:4001。本轮检测PC地址192.168.1.111，可能随网络变化。脚本默认监听0.0.0.0:4001，支持`-Port`参数。启动前检查指定端口：已有本项目服务时先停止，等待端口释放后重新启动；无监听时直接启动。无关进程占用、检查失败或10秒内端口未释放时拒绝启动。重启会结束现有服务，执行前应等待解析、保存及入库操作完成。不修改系统配置或防火墙。

根目录.env沿用POSTGRES_PASSWORD或MODOU_TEST_DATABASE_URL、DEEPSEEK_API_KEY及可选DEEPSEEK_MODEL；config.toml控制AI输出额度及Bangumi专用代理。密钥只在服务端读取。目前为受信局域网单管理员工具，无账号登录。运行单个服务进程，不使用多个实例共享草稿目录。

## 关闭

在项目根目录的PowerShell中执行（权限不足时使用管理员PowerShell）：

```powershell
.\scripts\stop_web.ps1
```

默认关闭4001端口的本项目审核服务。使用其他端口时指定`-Port 4010`；仅预览操作可加`-WhatIf`。脚本核对监听进程的本项目Python路径及`-m modou.web`启动模块，存在无关进程时拒绝停止；无监听时提示无需关闭。脚本直接结束服务进程，关闭前等待解析、保存及入库操作完成。前台启动的服务也可在原窗口按Ctrl+C停止。

1. 首页选择TXT（UTF-8/BOM或UTF-16，最大4MiB），点击解析。上传的是浏览器所在设备选中的文件。后台串行处理，完成后自动进入审核表；页面关闭后仍可从首页批次列表继续。

## Bangumi专用代理（c6e93a12）

