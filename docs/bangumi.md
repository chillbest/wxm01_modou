# Bangumi名称识别入口

## 当前自动识别流程（2026-11-19）

别名库（黑名单优先）→本地Bangumi→Bangumi API→DeepSeek候选选择，前序唯一命中即停止。GameFAQs产品链接AI兜底、其main识别及审核/URL入口同类AI补问已弃用，原实现以注释保留；后两轮批量阶段disabled，不再发请求。无命中保持未识别。历史第五槽和证据仍可展示，手填产品外链仍可保存；普通Bangumi主版本关系查询保留。main未知仍需人工确认，也可在edit输入半角/全角空格明确存NULL。

## 报价解析的当前AI批量契约（2026-11-17）

note_review及在线完整报价解析按10条固定分组，最多顺序调用3次DeepSeek（名称→GameFAQs→main），以item_id回填；无对应问题时跳过阶段，不自动重试。系统提示词及批量输入使用Markdown，不再要求edition；纯名称候选选择不要求平台，也不含PS4/PS5规则。独立bangumi_cli名称审核入口仍按单条名称调用，使用相同精简提示词。单条重新解析保持独立请求。在线分组交互详见docs/web-review.md。

> 人工核对表的现行完整格式与交互规范见[人工核对表格式与交互规范](review-format.md)。本文件后续逐次排版记录属于历史；发生冲突以该规范汇总的最新确认规则为准。

运行于项目根目录，使用.venv/Scripts/python.exe。Bangumi固定匿名，API使用config.toml中的[bangumi].proxy_url专用HTTP代理；DeepSeek使用既有.env配置并明确直连。完整代理规则见[在线审核代理说明](web-review.md#bangumi专用代理c6e93a12)。

输入JSON数组，每项包含raw_name（待识别名称）和note（原始笔记全文）。

```powershell
$env:PYTHONPATH='src'
.venv/Scripts/python.exe -m modou.bangumi_cli review .tmp/names.json --deepseek
```

不需要AI时省略--deepseek。默认扫描data/bangumi_locale日期最新ZIP，输出outputs/bangumi-review/Bangumi审核_六位哈希.md，拒绝覆盖。每批扫描约17秒，运行时间随机器变化。无匹配或API失败均保留候审状态。API搜索仅取前10项，不能因首项排名直接确认。

在Markdown的JSON块中逐条编辑status为confirmed或rejected；确认条目填写final。复用现有目录时只填写gpc_id；新条目填写name_zh，以及可空name_en、bangumi_id、bangumi_main。ID填写数字字符串，未知填null；主版本必须先于子版本确认导入。候选数据仅供参考，不能替代人工确认。

```powershell
.venv/Scripts/python.exe -m modou.bangumi_cli import outputs/bangumi-review/Bangumi审核_实际哈希.md
```

此命令会写modou_test，须审核后显式运行。仅写GPC及别名；整批事务，任一冲突回滚。不覆盖已有Subject资料，不写报价和正式库。旧memory_cli现在可读取GPC别名，但完整报价审核应使用下述note_review入口。

## 真实笔记报价审核（c8e42a71）

```powershell
$env:PYTHONPATH='src'
.venv/Scripts/python.exe -m modou.note_review review data/笔记.txt --date 2026-11-13 --deepseek
```

TXT支持UTF8/UTF16。第一行为标题，报价行采用“游戏名 PS4｜HK100｜凑-50”等现有格式；默认来源为输入文件路径，可用--source-path填写原文URL。--date填写笔记发布日期；行尾明确日期可覆盖报价日期。未提取的平台、地区、日期保留null，审核时必须补全。内容版本保留在识别名称中，不会因去除完全版或+DLC而误用基础版GPC。

输出outputs/note-review/笔记审核_六位哈希.md。每行保留原笔记、候选、AI建议、extracted原始解析证据及quote可编辑报价；status初始pending，final初始空。逐条确认GPC和quote字段后填confirmed；不采纳填rejected。即使别名唯一命中也须确认final.gpc_id。不要把候选ID填入gpc_id；Bangumi ID填final.bangumi_id。

```powershell
.venv/Scripts/python.exe -m modou.note_review import outputs/note-review/笔记审核_实际哈希.md
```

导入前全批验证；未审核或非法报价拒绝。确认项同一事务写GPC、别名、来源、报价，否决项不写入；同来源同报价重复执行复用已有记录。任一数据库错误整批回滚。仅允许0006的modou_test；不升级任何数据库，不写正式库。

价格查询仍待GPC适配，旧pricing接口不可用于当前四表结构。历史Doc笔记TXT当前不存在，相关真实样本测试明确跳过；需Karl选定实际TXT开展人工验收。当前平台提取支持原有PS4/PS5行内标签，其他平台可以人工填写；无明确标签保留待确认，不从Bangumi平台直接填报价。
